# Bugfix Capability

Evidence-driven reproduction, root cause, minimal fix, and regression closure.

## Responsibilities

- Reproduce bug with minimal reproducible case
- Identify root cause from runtime evidence
- Apply minimal fix without scope creep
- Verify fix with regression test

## Constraints

- Must collect runtime evidence before proposing fix
- Minimal fix only; no refactoring beyond fix scope
- Regression test must cover the fixed scenario
