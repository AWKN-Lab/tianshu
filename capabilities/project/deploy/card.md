# Windows + 阿里云部署卡

GitHub 只负责代码托管、分支冻结、提交历史和版本标签。验证、构建、迁移、灰度和上线在 Windows 与阿里云执行。

- 自动允许：本地预检、产物哈希、服务器只读检查、迁移 dry-run、灰度健康监控。
- 明确批准后允许：上传产物、生产迁移、切换流量、正式发布。
- 自动回滚仅在阈值、命令、备份和影响范围预先锁定时启用。
- IAM、DNS、防火墙、权限修改和无范围删除禁止自主执行。
- 生产完成必须报告版本、哈希、健康证据和回滚状态。
- 服务器部署范围内禁止名为 `.git` 的文件或目录，禁止 `git clone/fetch/pull/checkout/reset`；只允许上传不含 Git 元数据的不可变 ReleaseBundle。
- 远端预检必须递归检查目标根、版本目录和运行目录；发现 `.git` 立即 `BLOCKED`，不得继续，也不得未经批准删除。
- `git push` 只代表代码托管成功，不代表部署；没有 `DeployResult v1` 不得报告“部署成功”。
- 不得查询、触发或等待 GitHub Actions；runner、Actions Secrets 和通过标签不得作为部署门。
