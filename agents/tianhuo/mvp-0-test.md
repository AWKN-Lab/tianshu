## 演练场景

**模拟输入**：
> "这个方案我看不太懂，帮我检查一下安全配置，顺便看看哪里还能优化。"

**期望链路**：
1. ✅ **状态识别**："看不太懂" = 困惑信号 → Clarify 优先级提升
2. ✅ **意图澄清**：先说"我先确认一下你担心的点"
3. ✅ **能力路由**：安全配置 → SEC（安全组）；优化 → PROG（主程）
4. ✅ **验证声明**：审查完成后给出验证证据
5. ✅ **收尾确认**："刚才说的不清楚的地方，还需要再展开哪部分吗？"
