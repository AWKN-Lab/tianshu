## 🧬 进化产物 (Evolution Products)

### 产物 1: 技术债务量化指标系统

**名称**: TechDebt-Metrics  
**输入**: 代码库、Git 历史、测试覆盖率  
**输出**: 技术债务评分、优先级列表、优化建议  
**不变量**: 评分基于客观数据，非主观判断  
**变量**: 权重可根据项目类型调整  
**失败模式**: 数据不足时评分不准确  
**激活时机**: 每次代码审查前自动运行

**实现计划**:
```javascript
// 伪代码示例
async function calculateTechDebtScore(repo) {
  const metrics = {
    codeComplexity: await analyzeComplexity(repo),
    testCoverage: await getTestCoverage(repo),
    codeDuplication: await findDuplicates(repo),
    dependencyHealth: await checkDependencies(repo),
    documentationCoverage: await checkDocs(repo)
  };
  
  const score = weightedSum(metrics);
  const priority = prioritizeIssues(metrics);
  
  return { score, priority, recommendations: generateRecommendations(metrics) };
}
```

### 产物 2: 技术选型决策树

**名称**: TechStack-Decision-Tree  
**输入**: 项目需求、团队技能、预算、时间  
**输出**: 推荐技术栈、风险评估、学习成本  
**不变量**: 基于数据和案例，非个人偏好  
**变量**: 权重可根据公司战略调整  
**失败模式**: 新技术缺乏历史数据  
**激活时机**: 新项目启动或技术重构前

**决策树结构**:
```

│  ├─ 快速原型 → Vite + Express + SQLite
│  └─ 企业级 → Angular + Nest.js + PostgreSQL
├─ 移动应用
│  ├─ 跨平台 → React Native / Flutter
│  └─ 原生 → Swift / Kotlin
└─ AI/ML
   ├─ 训练 → Python + PyTorch
   └─ 推理 → Node.js + ONNX
```

### 产物 3: PR 自动审查系统

**名称**: Auto-PR-Reviewer  
**输入**: PR 链接、代码变更  
**输出**: 审查报告、风险评分、改进建议  
**不变量**: 必须包含安全扫描  
**变量**: 审查严格度可根据项目调整  
**失败模式**: 误报/漏报  
**激活时机**: 每次 PR 创建时自动触发

**审查维度**:
1. 代码质量 (复杂度、重复率、命名规范)
2. 安全性 (SQL 注入、XSS、敏感信息泄露)
3. 性能 (N+1 查询、内存泄漏风险)
4. 测试覆盖 (新增代码是否有测试)
5. 文档完整性 (是否有更新文档)
