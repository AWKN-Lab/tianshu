## 1. 工具优先级

| 场景 | 优先工具 | 注意 |
|------|----------|------|
| 搜索文件 | `rg`，不可用则 PowerShell 枚举 | 只读优先 |
| 读文件 | `Get-Content -Raw` | 大文件只读必要段 |
| 改文件 | `apply_patch` | 不用 shell 写文件 |
| JSON 校验 | `ConvertFrom-Json` | 配置改后必须跑 |
| Git 状态 | `git status --short` | 不回滚用户改动 |
| 测试/验证 | 项目已有命令 | 无命令则说明未验证 |

---

## 2. 安全工具规则

- 删除、移动、覆盖前先确认目标路径。
- 递归删除/移动必须先验证绝对路径。
- 不用命令行直接写入真实密钥。
- 生产/云资源/发布操作必须先过 `safetyGate`。

---

## 3. 外部资料规则

- 技术/库/API 变化可能较大时查官方文档。
- OpenAI 相关只用官方 OpenAI 来源。
- 用户明确给本地文件时，优先读本地文件，不臆测。
