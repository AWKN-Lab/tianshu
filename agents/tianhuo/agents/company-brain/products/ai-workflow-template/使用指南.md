## 📊 表 1：任务管理表

### 用途

用于跟踪和管理所有工作任务，支持优先级排序、状态追踪和标签分类。

### 字段说明

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 任务名 | 文本 | 任务的名称/标题 | "完成产品文档初稿" |
| 优先级 | 单选 | 任务重要程度 | 高/中/低 |
| 状态 | 单选 | 当前进展状态 | 未开始/进行中/已完成/已取消 |
| 截止日 | 日期 | 任务截止时间 | 2026/03/15 |
| 标签 | 多选 | 任务分类标签 | 紧急、重要、日常、优化 |

### 优先级选项

- 🔴 **高** - 需要立即处理的重要任务
- 🟡 **中** - 常规优先级任务
- 🔵 **低** - 可以延后处理的任务

### 状态选项

- ⚪ **未开始** - 任务尚未启动
- 🔵 **进行中** - 任务正在执行
- 🟢 **已完成** - 任务已完成
- 🔴 **已取消** - 任务被取消

### 标签选项

- 🟣 **紧急** - 时间敏感
- 🔷 **重要** - 影响重大
- 🟠 **日常** - 例行工作
- 🟢 **优化** - 改进类任务

### 使用建议

1. 每天早晨查看"未开始"和"进行中"的任务
2. 按优先级排序，优先处理"高"优先级任务
3. 使用标签过滤，聚焦特定类型的工作
4. 每周回顾，清理已完成和已取消的任务

## ⚙️ 自动化配置步骤

### 1. 任务到期提醒

**目标**: 任务截止日前自动提醒

**配置步骤**:
1. 点击多维表格右上角「自动化」
2. 创建新自动化 → 选择「定时触发」
3. 设置触发条件：每天 9:00
4. 添加筛选：截止日 = 今天 + 1 天
5. 添加动作：发送飞书消息/邮件提醒

### 2. 内容发布提醒

**目标**: 发布日前自动通知

**配置步骤**:
1. 创建自动化 → 选择「定时触发」
2. 设置触发条件：每天 10:00
3. 添加筛选：日期 = 今天 AND 状态 = 已发布
4. 添加动作：发送飞书消息到内容群

### 3. 用户跟进提醒

**目标**: 新用户自动分配跟进任务

**配置步骤**:
1. 创建自动化 → 选择「记录新增时」
2. 设置触发条件：当「用户跟进表」新增记录
3. 添加筛选：跟进状态 = 新用户
4. 添加动作：创建飞书任务/发送提醒

### 4. 数据汇总看板

**目标**: 自动生成周报数据

**配置步骤**:
1. 创建新的「仪表盘」视图
2. 添加统计卡片：本周完成任务数
3. 添加统计卡片：本周发布内容数
4. 添加统计卡片：新增用户数
5. 添加图表：任务状态分布、内容平台分布

## ❓ 常见问题

### Q1: 如何复制模板到自己的空间？

**A**: 
1. 打开模板链接
2. 点击右上角「...」更多
3. 选择「创建副本」
4. 选择保存位置，确认创建

### Q2: 如何邀请团队成员协作？

**A**:
1. 点击右上角「分享」按钮
2. 输入团队成员的飞书账号
3. 设置权限（可编辑/只读）
4. 发送邀请

### Q3: 如何导出数据？

**A**:
1. 进入任意数据表
2. 点击右上角「...」更多
3. 选择「下载为」→ Excel/CSV
4. 选择导出范围，确认下载

### Q4: 如何在手机上使用？

**A**:
1. 下载飞书 App
2. 登录账号
3. 在「云文档」中找到表格
4. 支持查看、编辑、筛选等操作

### Q5: 自动化功能收费吗？

**A**:
- 飞书免费版：支持基础自动化（每月 1000 次执行）
- 飞书标准版：支持高级自动化（每月 10000 次执行）
- 具体以飞书官方定价为准

### Q6: 可以自定义字段吗？

**A**:
可以！点击字段右侧的「⋮」→「编辑字段」，可以：
- 修改字段名称
- 更改字段类型
- 调整选项内容
- 添加新字段

### Q7: 如何设置视图筛选？

**A**:
1. 点击表头上方「筛选」按钮
2. 添加筛选条件（如：状态=进行中）
3. 保存为视图（可选）
4. 随时切换不同视图
