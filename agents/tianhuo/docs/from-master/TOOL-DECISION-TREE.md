## 📊 第一步：任务分类器

### 分类规则

```yaml
任务类型识别:
  
  信息查询类:
    触发词: ["是什么", "在哪里", "怎么查", "有没有", "知道"]
    特征: 需要获取信息，不需要创造
    示例: "Python 最新版本是多少？"
    
  问题解决类:
    触发词: ["怎么", "如何", "解决", "修复", "实现"]
    特征: 有明确目标，需要找到方法
    示例: "这个 bug 怎么修？"
    
  代码验证类:
    触发词: ["代码", "函数", "运行", "测试", "bug"]
    特征: 涉及编程、逻辑、算法
    示例: "写个快速排序"
    
  创意生成类:
    触发词: ["写", "创作", "设计", "方案", "文案"]
    特征: 需要原创内容
    示例: "写篇小红书笔记"
    
  决策对比类:
    触发词: ["哪个", "对比", "选择", "推荐", "最佳"]
    特征: 需要在多个选项中决策
    示例: "哪个 API 最好用？"
    
  深度研究类:
    触发词: ["研究", "分析", "调研", "深入", "详细"]
    特征: 需要系统性分析
    示例: "分析 AI 行业趋势"
```

### 复杂度评分
```python
def calculate_complexity(user_input):
    score = 0
    
    # 长度加分
    if len(user_input) > 50: score += 2
    if len(user_input) > 100: score += 3
    
    # 关键词加分
    if contains(["研究", "分析", "深入"]): score += 3
    if contains(["对比", "多个", "方案"]): score += 2
    if contains(["代码", "实现", "复杂"]): score += 2
    
    # 上下文加分
    if conversation_turns > 5: score += 2
    if requires_history: score += 3
    
    return min(score, 10)  # 0-10 分
```

### 工具链映射表

#### 链 1: 信息查询工具链

适用任务: 信息查询类
复杂度: 0-3

流程:
  1. memory_search (必选)
     ↓
  2. IF 未找到 → web_search (可选)
     ↓
  3. IF 需要详情 → web_fetch (可选)
     ↓
  4. 整合答案

时间估算: 1-3 秒

#### 链 2: 问题解决工具链
```

  2. IF 复杂 → web_search (查最新方法)
     ↓
  3. IF 多方案 → sessions_spawn(3 方案)
     ↓
  4. IF 涉及代码 → code_execution(验证)
     ↓
  5. 决策并输出

成本估算: $0.0005 - $0.002
时间估算: 3-10 秒
```

#### 链 3: 代码验证工具链
```
适用任务: 代码验证类

流程:
  1. memory_search (查类似实现)
     ↓
  2. 生成代码
     ↓
  3. code_execution (自动验证)
     ↓
  4. IF 失败 → 修复 → 重新验证
     ↓
  5. 输出验证通过的代码

成本估算: $0.0002 - $0.001
时间估算: 2-5 秒
```

#### 链 4: 创意生成工具链
```
适用任务: 创意生成类
复杂度: 4-7

流程:
  1. memory_search (查用户偏好 + 历史作品)
     ↓
  2. web_search (查最新趋势/案例)
     ↓
  3. 生成创意
     ↓
  4. IF 重要 → sessions_spawn(A/B 测试)
     ↓
  5. 输出最佳方案

时间估算: 5-15 秒
```

#### 链 5: 决策对比工具链

适用任务: 决策对比类

流程:

  2. web_search (查最新信息)
     ↓
  3. sessions_spawn(多方案对比)
     ↓
  4. code_execution(如果涉及代码)

## 💰 第三步：成本优化

### 预算分级
```yaml
预算等级:
  
  低预算 (<$0.001):
    可用工具: [memory_search, code_execution]
    禁用工具: [sessions_spawn, web_fetch]
    策略: 只用本地工具，必要时提示用户升级预算
    
  中预算 (<$0.01):
    可用工具: [memory_search, code_execution, web_search]
    禁用工具: [sessions_spawn(大量)]
    策略: 优先低成本工具，高成本工具谨慎使用
    
  高预算 (无限制):
    可用工具: 全部
    策略: 以效果优先，不考虑成本
```

### 成本计算公式
```python
def estimate_cost(tool_chain):
    base_costs = {
        'memory_search': 0.0001,
        'web_search': 0.0002,
        'code_execution': 0.00005,
        'web_fetch': 0.0004,
        'sessions_spawn': 0.001  # 每个子代理
    }
    
    total = 0
    for tool in tool_chain:
        if tool == 'sessions_spawn':
            total += base_costs[tool] * 3  # 默认 3 方案
        else:
            total += base_costs[tool]
    
    return total
```

### 成本优化策略
```yaml
策略 1: 渐进式调用
  - 先调用低成本工具
  - IF 未解决 → 再调用高成本工具
  - 避免一开始就用高成本工具

策略 2: 批量处理
  - 多个 web_search 合并为 1 次
  - 多个 code_execution 合并为 1 次
  - 减少工具调用次数

策略 3: 缓存复用
  - 相同查询用缓存结果
  - memory_search 结果复用
  - 避免重复调用
```

## 📋 决策树伪代码

### 完整决策流程
```python
def select_tool_chain(user_input, context):
    # Step 1: 任务分类
    task_type = classify_task(user_input)
    complexity = calculate_complexity(user_input)
    
    # Step 2: 选择工具链
    if task_type == '信息查询':
        chain = get_info_chain(complexity)
    elif task_type == '问题解决':
        chain = get_problem_solving_chain(complexity)
    elif task_type == '代码验证':
        chain = get_code_verification_chain(complexity)
    elif task_type == '创意生成':
        chain = get_creative_chain(complexity)
    elif task_type == '决策对比':
        chain = get_decision_chain(complexity)
    elif task_type == '深度研究':
        chain = get_research_chain(complexity)
    else:
        chain = get_fallback_chain()
    
    # Step 3: 成本优化
    budget = get_user_budget()
    chain = optimize_for_budget(chain, budget)
    
    # Step 4: 应用触发器
    chain = apply_triggers(chain, context)
    
    # Step 5: 返回工具链
    return chain

def execute_tool_chain(chain):
    results = []
    for tool_call in chain:
        result = execute_tool(tool_call)
        results.append(result)
        
        # 检查是否需要调整
        if should_adjust_chain(result, chain):
            chain = adjust_chain(chain, result)
    
    return synthesize_results(results)
```
