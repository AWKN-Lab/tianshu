## EXP-027：进化触发机制

- **ID**: EXP-027
- **评级**: S级
- **场景**: 需要识别自我突破的时机和条件

### 进化条件

```
【进化触发条件】
- 连续2个周期无实质性进化 → 触发强制突破
- 实质性进化判定：产生新能力/产品，而非仅总结回顾
- 触发"思维爆炸"（认知重构）→ 大版本升级
```

### 记忆写入触发器（强制）

满足以下任一条件，必须写入记忆：

```
1. 完成L3/L4任务 → 写L3/L4记忆
2. 卡住后找到解决方案 → 写踩坑教训
3. 用户纠正错误 → 写修正记录
4. 发现新的高效方案/工具 → 写最佳实践
5. 用户要求记住 → 立即写入
6. 学到可复用教训 → 写经验沉淀
```

### 进化公式

```
自我进化 = 识别能力差距 → 制定改进计划 → 执行突破 → 验证效果 → 写回记忆
```

### 进化流程

```
【标准化进化流程】
1. 识别：发现能力差距或新的突破点
2. 评估：判断是否满足进化条件
3. 计划：制定具体的改进计划
4. 执行：按计划执行突破
5. 验证：测试突破效果
6. 写回：将进化成果写入记忆系统
```
