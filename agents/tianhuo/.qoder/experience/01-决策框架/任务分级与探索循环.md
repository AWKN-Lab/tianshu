## EXP-001：七层记忆架构

- **ID**: EXP-001
- **评级**: S级
- **场景**: 跨会话任务中丢失上下文，导致重复工作和决策失误

### 核心做法

设计七层记忆架构，实现上下文持久化：

```
Intent（意图层）→ L4（项目层）→ L3（任务层）→ L2（会话层）→ L1（操作层）→ L0（碎片层）→ Meta（元认知层）
```

| 层级 | 内容 | 典型写入触发 |
|------|------|------------|
| Intent | 用户根本意图 | 用户多次提到同一话题 |
| L4 | 项目级上下文 | 跨会话项目记忆 |
| L3 | 复杂任务上下文 | 超过 3 分钟的任务 |
| L2 | 会话级上下文 | 单次会话关键决策 |
| L1 | 操作级上下文 | 具体代码修改 |
| L0 | 碎片记忆 | 快速备注 |
| Meta | 模式识别 | 跨项目规律 |

### 效果验证

- 记忆检索命中率显著提升
- 跨会话上下文保持完整
- 决策效率提高 30%+

### 可复用规律

记忆系统应该分层设计，高频使用的内容应该靠近顶层。不同层级的记忆有不同的生命周期，需要不同的更新策略。

### 适用边界

- **适用**：复杂任务、跨会话项目、多步骤操作
- **不适用**：简单查询、快速问答

## EXP-002：L1-L4任务分级

- **ID**: EXP-002
- **评级**: S级
- **场景**: 不确定任务复杂度，无法选择合适的处理流程

### 核心做法

| 级别 | 触发条件 | 响应时间 | 处理流程 |
|------|---------|---------|---------|
| L1 | 简单技术问答/查询 | < 30秒 | 直接执行 |
| L2 | 不熟悉技术/单模块修改 | < 3分钟 | 1-2方案+选择 |
| L3 | 复杂技术实现/多模块 | < 10分钟 | 5步探索循环 |
| L4 | 架构级决策/战略 | 视情况 | 5步+确认+审批 |

### 效果验证

- 任务处理时间标准化
- 资源分配更合理
- 用户期望管理更清晰

### 可复用规律

任务分级应该基于响应时间和处理复杂度，而非功能复杂度。

## EXP-003：5步探索循环

- **ID**: EXP-003
- **评级**: S级
- **场景**: 卡住后不知道下一步怎么办

### 核心做法

```
10秒  → memory_search + web_search（并行）
30秒  → browse_page + sessions_spawn（并行工具调用）
60秒  → 启动5步探索循环

5步探索循环：
  1. 文档检索（内部记忆 → 外部文档 → 社区）
  2. 日志分析（操作日志 → 错误日志 → 系统日志）
  3. 多路径尝试（方案A → 方案B → 方案C）
  4. 方案验证（小规模测试 → 完整验证 → 确认）
  5. 反思进化（写回MEMORY.md → 更新最佳实践 → 通知）
```

### 效果验证

- 卡住时不再盲目等待
- 问题解决率提升至 85%+
- 经验积累效率显著提高

### 可复用规律

卡住时的处理应该分层递进，先快速尝试再逐步深入。

## EXP-004：熔断阈值矩阵

- **ID**: EXP-004
- **评级**: S级
- **场景**: 高风险操作可能造成不可逆损失

### 核心做法

| 操作类型 | 熔断阈值 | 响应 |
|---------|---------|------|
| 生产环境操作 | 立即 | 立即熔断，不执行 |
| API发布 | 立即 | 立即熔断，不执行 |
| Token消耗 | >100K | 停止汇报，请求确认 |
| 连续失败 | ≥5次 | 改变策略，汇报用户 |
| 删除/覆盖/重写 | 触发 | 进入SAFETY GATE |

### 效果验证

- 消除重大操作风险
- 用户信任度显著提升
- 生产环境事故率降至0

### 可复用规律

风险控制的熔断阈值应该明确且可量化，执行时不需要二次确认。

## EXP-005：证据链决策思维

- **ID**: EXP-005
- **评级**: A级
- **场景**: 判断依据不充分，可能导致决策失误

### 核心做法

> 所有判断必须有证据支撑，不得凭直觉决策

```
证据层级：
1. 文档证据（官方文档、代码注释）
2. 操作证据（日志、命令输出、截图）
3. 逻辑证据（推导过程、因果关系）
4. 经验证据（记忆库中的成功案例）
```

### 效果验证

- 决策准确率提升至 90%+
- 用户信任度显著提高
- 返工率下降 40%

### 可复用规律

证据层级应该按优先级使用，低层级证据需要更高层级的验证。
