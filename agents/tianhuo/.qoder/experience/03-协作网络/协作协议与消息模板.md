## EXP-010：子智能体调用规则

- **ID**: EXP-010
- **评级**: S级
- **场景**: 协作网络混乱，不知道该调用哪个子智能体

### 角色定位

| 角色 | 代号 | 定位 | 触发关键词 |
|------|------|------|------------|
| 天火智能体 | 火 | CTO/主智能体，总指挥 | 发起任务 |
| 大掌柜 | 柜 | 执行者，负责落地执行 | 文件/日志/记忆/执行 |
| 审计官 | 审 | 审查者，负责质量把关 | 审查/校验/审计/评估 |
| 调度官 | 调 | 协调者，负责任务分解 | 分解/追踪/协调/排期 |

### 优先级

```
天火 > 调度官 > 审计官 > 大掌柜
```

### 调用场景矩阵

| 场景 | 触发者 | 被调用者 |
|------|--------|----------|
| 任务需要分解 | 天火 | 调度官 |
| 需要执行落地 | 天火/调度官 | 大掌柜 |
| 需要质量把关 | 天火/调度官 | 审计官 |
| 审查通过后继续 | 审计官 | 天火/调度官 |
| 执行完成后记录 | 大掌柜 | 天火 |

## EXP-013：禁止反向调用规则

- **ID**: EXP-013
- **评级**: S级
- **场景**: 子智能体越权调用，导致协作网络混乱

### 禁止规则 ⚠️ Critical

```
禁止反向调用：
├─ 大掌柜 → 调度官：禁止
├─ 大掌柜 → 审计官：禁止
├─ 审计官 → 调度官：禁止
└─ 子智能体之间：禁止直接通信，必须经过天火
```

### 后果

违反禁止规则将导致：
- 协作网络崩溃
- 责任边界模糊
- 任务追踪困难

### 正确做法

所有子智能体间的通信必须经过天火智能体：
```
大掌柜有问题 → 汇报天火 → 天火协调审计官/调度官
```

## EXP-012：状态同步枚举

- **ID**: EXP-012
- **评级**: A级
- **场景**: 任务状态不一致，难以追踪进度

### 状态枚举

| 状态码 | 状态名 | 说明 |
|--------|--------|------|
| PENDING | 待领取 | 任务已创建，等待领取 |
| IN_PROGRESS | 进行中 | 正在执行 |
| REVIEWING | 审查中 | 提交审查 |
| BLOCKED | 阻塞中 | 等待前置条件 |
| COMPLETED | 已完成 | 执行完成 |
| REJECTED | 已驳回 | 审查不通过 |
| CANCELLED | 已取消 | 任务取消 |

### 状态同步时机

| 事件 | 触发者 | 状态变更 | 必须字段 |
|------|--------|---------|---------|
| 任务领取 | 大掌柜 | PENDING → IN_PROGRESS | 时间戳 |
| 任务开始 | 大掌柜 | 记录开始时间 | 开始时间 |
| 遇到阻塞 | 大掌柜 | IN_PROGRESS → BLOCKED | 阻塞原因 |
| 阻塞解除 | 调度官 | BLOCKED → IN_PROGRESS | 解阻塞说明 |
| 提交审查 | 大掌柜 | IN_PROGRESS → REVIEWING | 交付物路径 |
| 审查通过 | 审计官 | REVIEWING → COMPLETED | 审查意见 |
| 审查驳回 | 审计官 | REVIEWING → REJECTED | 驳回原因 |
| 任务取消 | 天火 | * → CANCELLED | 取消原因 |

**下次遇到类似情况，先做哪3件事？

1. 确认角色优先级（天火 > 调度官 > 审计官 > 大掌柜）
2. 检查是否符合调用场景矩阵
3. 使用标准消息模板格式
