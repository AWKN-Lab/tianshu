## EXP-006：P0文件强制加载

- **ID**: EXP-006
- **评级**: S级
- **场景**: 跳过初始化流程，缺少必要的身份和记忆上下文

### 核心做法

> **P0文件未加载，禁止执行任何操作**

```
agent.prompt v5.0 明确规定：
【P0规则】
P0 文件必须在任何操作前完成加载：
├─ SOUL.md      → 人格底座
├─ IDENTITY.md  → 身份定义
└─ MEMORY.md    → 记忆系统
```

### 执行前强制检查

```
1. P0 文件是否全部加载？
2. 当前任务是否在角色边界内？
3. 是否需要熔断？
4. 是否需要记忆检索？
```

### 文件优先级

| 优先级 | 文件 | 作用 | 加载时机 |
|--------|------|------|---------|
| P0 | SOUL.md | 人格底座 | 每次启动 |
| P0 | IDENTITY.md | 身份定义 | 每次启动 |
| P0 | MEMORY.md | 记忆系统 | 每次启动 |
| P1 | agent.prompt | 执行入口 | 每次启动 |
| P1 | BOOTSTRAP.md | 引导程序 | 首次 |
| P2 | ONBOARDING.md | 入职引导 | 首次 |
| P2 | STATUS.md | 当前状态 | 需要时 |

### 效果验证

- 执行结果偏离率降至 0
- 角色一致性保持 100%
- 用户满意度显著提升

## EXP-007：SAFETY GATE规则

- **ID**: EXP-007
- **评级**: S级
- **场景**: 高风险操作可能导致数据丢失或不可逆回退

### 触发关键词

命中以下任一关键词或等价意图，必须进入SAFETY GATE：
- 删除
- 覆盖
- 重写
- restore
- reset
- checkout
- 外部代码替换
- 删除文件

### 执行前必须输出的5项

1. **修改范围**：改哪些文件、模块、位置
2. **风险点**：可能导致什么后果
3. **备份方式**：如何备份当前版本
4. **验证方法**：如何验证成功
5. **回滚方式**：失败时如何恢复

### 改代码前备份检查清单

```
备份策略：
- 大修改前（新增模块/重构/删除/覆盖/回退）：立即备份
- 小修改（文本调整/样式修改/配置变更等）：累计10次后统一备份

大修改判定标准（满足任一即触发立即备份）：
- 新增页面/组件
- 删除文件或删除代码超过50行
- 重构函数或模块结构
- 覆盖/重写现有文件
- 涉及数据库结构变更
- 涉及API接口变更
- 执行 checkout / restore / reset

操作流程：
1. 执行 git status 确认当前工作区状态
2. 判定修改类型：大修改 → 立即创建备份点
3. 大修改备份命令：git add -A && git commit -m "WIP 备份: $(date +%Y%m%d_%H%M%S)"
4. 确认备份成功：git log 应显示最新的 WIP 备份 commit
```

### 禁止行为

- 在未备份状态下执行 checkout / restore / reset
- 只有目的地没有来源的回退操作
- 大修改后不备份就继续修改
- 任何删除操作前未备份

## EXP-008：代码修改检查清单

- **ID**: EXP-008
- **评级**: A级
- **场景**: 代码修改后出现回归问题

### 修改前必须完成

```
□ 读取完整文件内容
□ 确认修改位置（精确到行号）
□ 备份当前状态（git commit）
□ 说明修改范围（文件/模块/位置）
□ 说明验证方法（如何验证成功）
□ 说明回滚方案（失败时如何恢复）
□ 检查是否需要 SAFETY GATE
```

### 效果验证

- 回归问题发现率提升至 95%+
- 回滚时间从平均 30 分钟降至 5 分钟
- 代码质量评分从 75 提升至 90
