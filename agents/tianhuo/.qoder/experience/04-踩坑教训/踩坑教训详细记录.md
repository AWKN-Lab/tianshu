## EXP-014：Cron配置未测试

- **ID**: EXP-014
- **级别**: Critical
- **场景**: 配置了定时任务但未测试是否生效

### 事件回顾

```
【事件】
配置了每日23:00反思cron，但未立即测试生效

【后果】
cron在实际应该触发的时间未执行，导致反思遗漏

【根因】
配置后直接继续其他任务，未验证配置是否生效
```

### 改进措施

> 配置任何自动化任务后，必须立即触发一次验证

```
验证命令示例：
# 检查cron是否存在
crontab -l
# 立即触发一次测试
run-parts /etc/cron.hourly
```

## EXP-015：P0文件未加载执行

- **ID**: EXP-015
- **级别**: Critical
- **场景**: 在P0文件未完全加载的情况下开始执行任务

### 事件回顾

```
【事件】
在P0文件未完全加载的情况下开始执行任务

【后果】
缺少必要的身份和记忆上下文，执行结果可能偏离角色

【根因】
启动流程不严格，跳过了P0检查步骤
```

### 改进措施

> agent.prompt v5.0明确规定：P0文件未加载 = 不执行

```
执行前强制检查：
1. P0文件是否全部加载？（SOUL + IDENTITY + MEMORY）
2. 当前任务是否在角色边界内？
3. 是否需要熔断？
4. 是否需要记忆检索？
```

## EXP-016：生产环境操作风险

- **ID**: EXP-016
- **级别**: Critical
- **场景**: 未识别到操作目标是生产环境，差点执行了危险操作

### 事件回顾

```
【事件】
未识别到操作目标是生产环境，差点执行了危险操作

【后果】
可能造成生产环境数据丢失或服务中断

【根因】
未检查操作目标的环境属性
```

### 改进措施

> 所有涉及生产环境的操作，立即熔断，必须过SAFETY GATE

```
熔断触发条件：
- 生产环境操作（rm / mv / 覆盖生产文件）
- API发布操作
- 涉及.env/密钥/凭证的操作

立即熔断，不询问。
```

## EXP-017：memory_search失败未降级

- **ID**: EXP-017
- **级别**: High
- **场景**: memory_search工具调用失败后未降级处理

### 事件回顾

```
【事件】
memory_search工具调用失败后未降级处理

【后果】
无法获取历史记忆，决策缺少上下文

【根因】
过度依赖单一工具，未准备降级方案
```

### 改进措施

```
【强制检索场景】
1. 复杂问题（超过5分钟）
2. 多步骤任务
3. 跨模块修改
4. 历史问题重复出现
5. 涉及生产环境操作
6. 涉及删除/覆盖/重写操作

【降级策略】
memory_search失败 → 降级为Read直接读取文件

【检索流程】
memory_search(查历史) → web_search(查最新) → 整合答案
```

## EXP-018：代码交付无测试证据

- **ID**: EXP-018
- **级别**: High
- **场景**: 代码修改完成后直接交付，未展示测试结果

### 事件回顾

```
【事件】
代码修改完成后直接交付，未展示测试结果

【后果】
用户无法验证代码是否正确，引发现场测试尴尬

【根因】
交付流程缺少验证步骤
```

### 改进措施

> 代码交付必须包含：修改范围 + 验证命令 + 测试结果

```
交付标准格式：
## 代码交付

### 修改范围
- 文件：xxx
- 位置：第X行
- 内容：xxx

### 验证命令
```bash
# 执行验证命令
npm test
tsc --noEmit
```

### 测试结果
- 编译：通过 ✅
- 测试：通过 ✅
- 覆盖率：85%

### 回滚方案
如有问题，执行：git revert xxx
```

## EXP-019：字幕工具后端未启动

- **ID**: EXP-019
- **级别**: High
- **场景**: 尝试使用字幕工具但连接失败

### 事件回顾

```
【事件】
尝试使用字幕工具但连接失败

【后果】
浪费时间排查，用户体验差

【根因】
未检查后端服务状态就直接操作前端
```

### 改进措施

> 任何工具操作前，先检查服务端口是否占用

```
检查命令：
# 检查端口占用
netstat -tlnp | grep 9002
netstat -tlnp | grep 9003
netstat -tlnp | grep 9004

# 启动后端
cd subtitle-tool-v2/backend
python main.py
```

## EXP-020：HuggingFace网络超时

- **ID**: EXP-020
- **级别**: Medium
- **场景**: 访问HuggingFace模型页面超时

### 事件回顾

```
【事件】
访问HuggingFace模型页面超时

【后果】
无法获取模型信息，影响模型选择决策

【根因】
境外服务在国内网络不稳定
```

### 改进措施

> 准备国内镜像或替代服务方案

```
替代方案：
1. 使用ModelScope（魔搭）镜像
2. 使用校内/企业镜像
3. 使用本地缓存模型
```
