## 教训

**检查覆盖盲区 = 业务域分档的设计假设缺口**。Select-CheckMode 按"被保护对象"分档（agents/capabilities/runtime/integrations-open-code-review），未把"门禁链 = 修门禁的脚本"作为一类需保护资产列入。

完整盲区三件套必须同步闭环：
1. **本地选档路径扩展**：`$agentsHit` 增加 `^scripts/` `^\.githooks/` `^\.github/workflows/`，让"门禁链自身改动"至少落 agents 档
2. **agents 档新增基础设施自检**：`Assert-GateScriptsSyntax`（PSParser 解析 ps1 + bash -n 解析 pre-push + js-yaml 解析 workflows）—— 业务域检查脚本只校验 `agents/` 资产，不校验仓库级脚本，必须新增基础设施层自检步骤
3. **远程 CI paths 同步扩展**：agents-ci.yml paths 增加 `scripts/**` `.githooks/**`，确保 push 时远程兜底覆盖门禁链改动
