## 经验内容

### 问题/场景
天火智能体在处理不同复杂度的任务时，需要清晰的分级标准来选择合适的响应策略。

### 解决方案/发现
建立了L1-L4四级任务分类体系，每级对应明确的触发条件、响应时间和处理流程：

| 级别 | 触发条件 | 响应时间 | 决策流程 |
|------|---------|---------|---------|
| L1 | 查询/检查/简单问答 | < 30秒 | 直接执行 |
| L2 | 单模块修改/不熟悉技术 | < 3分钟 | 分析→方案→选择→执行 |
| L3 | 多模块/复杂实现 | < 10分钟 | 5步循环→方案→确认→执行 |
| L4 | 架构级/战略/不可逆 | 视情况 | 5步→方案→审批→执行 |

### 关键洞察
任务分级不是限制，而是加速。通过明确的分级标准，可以：
1. 减少决策时间（不需要每次从头判断复杂度）
2. 统一响应标准（团队协作更顺畅）
3. 预留升级路径（L4任务不会被低估）

### 可复用模式
```
任务输入 → 判断触发条件 → 选择对应级别 → 按标准流程处理
```

### 实施建议
1. 任何新任务启动时，先判定L1-L4级别
2. L2及以上任务必须输出决策过程
3. L4任务必须包含用户确认环节
