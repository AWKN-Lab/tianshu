- 证据 2：ahead 4 期间 commit 单独跑都命中 agents 档（agents/scripts/.githooks 改动），从未触发 full 档链式 test:all
- 证据 3：EXP-DRV-005/009 §4.3 已识别"档位继承对齐 vs 远程触发语义不对齐"，本候选是"Ahead 链整体应被对待为一个 push-time full 档事件"的进一步识别

## 反例

```powershell
# 错误：Ahead 链拆为单 commit 跑 agents 档（漏掉链式调用 bug）
git log @{u}..HEAD  # 看 ahead N
foreach ($c in $commits) {
    $files = git diff-tree --no-commit-id --name-only -r $c
    pwsh ./scripts/local-ci.ps1 auto -ChangedFilesFile <($files -join "`n")
}
# 问题：每个 commit 单独跑命中 agents 档（agents/scripts/.githooks），从未触发 full 档链式 test:all

# 正确：Ahead 链整体作为一个 push-time 事件跑完整 full 档
git diff --name-only @{u}..HEAD > /tmp/ahead.diff
pwsh ./scripts/local-ci.ps1 auto -ChangedFilesFile /tmp/ahead.diff
# 命中 full 档（含 architecture + test:all + build），提前发现链式调用 bug
```

- 本地预跑成本：~15~30 分钟（含 architecture + test:all + build）；ahead 链越长越值得预跑
