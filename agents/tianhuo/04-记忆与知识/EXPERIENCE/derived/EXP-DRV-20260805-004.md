## 教训

**任何"Runtime 治理会自动扫描 DRAFT 候选"的声称必须实测验证**，不可推断。三层都可能独立失效：
1. **驱动层**：cron 队列无 "evolve scan" 类触发，或 run_count = 0
2. **格式层**：扫描器只识别特定格式模板（如 `**状态**: 待人工补充`），新格式如 `状态: DRAFT` 不被识别
3. **通道层**：awkn-engine MCP transport 断连 + runtime HTTP 端口未监听

## 反例

```bash
# 错误：推断式声称

"明天起来这些就变 ACTIVE 了"
# 实际：扫不到 + 推不上 + 通道不稳 三层同时坏

# 正确：实测验证（先看通道再看格式再看驱动）
awkn_evolve_scan_drafts
awkn_evolve_list --status=DRAFT
awkn_cron_list | grep -i 'evolve\|scan'
```

## 三层验证法（落地步骤）

1. **通道层**：`awkn_evolve_scan_drafts` 立即返回值？若 transport error → 进非 MCP 路径（curl localhost:9000/get-Process node 列表）
2. **格式层**：scan_drafts 返回 N 条？用 N vs derived/ 下文件数对比判断识别率
3. **驱动层**：`awkn_cron_list --filter=evolve` → 看 run_count > 0 的 cron 是否真存在

## 验收

- **不**在任何报告里写"Runtime 治理会自动 X"除非已实测

- 修复入口必须用户授权才做（按"只观察不修改"硬规则）
