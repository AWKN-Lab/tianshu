# EXP-DLG-20260802-004：PowerShell native 命令退出码必须用 $LASTEXITCODE

## 候选要点

- `-not (git cat-file -e ...)`：成功时无 stdout → 表达式值为 `$null` → `-not $null` = `$true` → 恒报"缺失"。
- 正确：`git cat-file -e ...; if ($LASTEXITCODE -ne 0) { ... }`。
- 复核代码比初检更"聪明"却更脆弱——本次初检正确、复核反引入 bug。
