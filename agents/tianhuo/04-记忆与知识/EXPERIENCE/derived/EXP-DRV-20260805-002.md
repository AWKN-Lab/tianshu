# EXP-DRV-20260805-002｜多 Agent ahead 整链对账

**状态**: DRAFT
**类型**: DERIVED
**适用范围**: 多 session 共享 git author 时 push 前的归属判断
**关联 commit**: 04f3f4b + 6601ff7（ahead 链里非当前 session 的 commit）

## 教训

**多 Agent 工作流的 git author 不可信为归属边界**——必须靠 `commit time + commit content + author email` 三维度交叉判断。

- 证据 1：04f3f4b (08-04 21:27) 和 6601ff7 (08-05 06:45) 都是 laychen1983 author，与当前 session 的 b117af2 / 81e52ef 同 author
- 证据 2：单纯靠 author email 区分"我的 commit" 会错过同身份的其他 session

## 反例

```bash
# 错误：默认 ahead 链都是我的
git log tianshu/main..main --oneline
# 04f3f4b ...
# 6601ff7 ...
# 直接 git push → 替他人 session 代签所有 commit

# 正确：逐条对账
for sha in $(git log tianshu/main..main --format=%H); do
  time=$(git log -1 --format='%ad' $sha)
  msg=$(git log -1 --format='%s' $sha)
  echo "$sha $time $msg"
done
# 然后按时间 + content 区分"我本次 session 写的"
```

## 验收

- ahead chain N > 1 时绝不默认全部推送
- 每条 ahead commit 都要用户**明确语义授权**（不是"全部"字面，是"你认识的这些哪些该推"）
- 提交 commit 时把 ahead 链也写进 commit message 备注（如已提交的 ahead commits 不属于本 commit）
