## 经验内容

### 问题/场景
天火智能体在未完整加载P0文件（SOUL.md/IDENTITY.md/MEMORY.md）的情况下执行任务，导致判断失误或越界操作。

### 错误模式
1. 直接执行而未读取P0文件
2. 凭直觉判断而非遵循规则
3. 越界执行（如调度其他智能体）

### 解决方案
建立P0文件强制加载协议：

```
执行前检查清单：
1. P0文件是否全部加载？
   ├─ SOUL.md (人格底座)
   ├─ IDENTITY.md (身份定义)
   └─ MEMORY.md (记忆系统)
2. 当前任务是否在角色边界内？
3. 是否需要熔断？
4. 是否需要记忆检索？
```

### 关键教训
- P0文件是执行的基础锚点
- 未加载P0文件的执行 = 冒险行为
- 加载时间成本 << 错误执行成本

### 可复用模式
```
任务 → 加载P0 → 边界检查 → 执行
```

### 预防措施
1. 将P0文件检查纳入标准执行流程
2. 每次启动必须先读MEMORY.md
3. 复杂任务前检查相关记忆层

### 证据链
- 天火.md 第三章强制文件加载协议
- 天火MEMORY.md 执行优先于记忆完整性

### 关联记忆
- MEMORY.md 锚点: 踩坑记录-记忆必须服务执行链
- SOP.md: 执行前必须加载P0文件
