# EXP-FIX-20260806-001｜Verify 测试在链式执行中必须使用唯一临时目录

## 问题

单文件测试能够通过，但在 `test → contracts → verify` 链式执行中，固定临时目录和数据库文件可能保留锁、迁移记录或异常退出产物，造成 `EBUSY`、唯一约束冲突和恢复失败。

## 修复规则

- 临时目录包含 `process.pid` 和时间或随机因子。
- 测试开始前执行幂等清理。
- 所有数据库连接在退出前关闭。
- `finally` 中清理临时目录。
- 测试必须同时通过独立执行和链式执行。

## 反例

```text
错误：所有运行复用 test-tmp/example.db。
正确：每次运行生成唯一目录，并在 finally 中关闭数据库和清理文件。
```

## 验证

- 独立 verify 测试通过。
- 完整 `test:all` 连续执行两次均通过。
- 异常中断后再次运行不会命中旧锁和旧迁移状态。

## 授权边界

只修改测试夹具、临时目录和清理逻辑，不改变业务数据库和生产迁移语义。

## 失效条件

当 Verify Runner 为每个测试创建独立进程、目录和数据库沙箱后，本经验可并入统一测试运行器规范。
