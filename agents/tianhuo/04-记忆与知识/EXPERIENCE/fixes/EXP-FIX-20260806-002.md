# EXP-FIX-20260806-002｜退役：禁止用被忽略的 worktree 副本绕过真实契约缺失

## 原候选

原候选建议在被 Git 忽略的目录中创建临时 schema 副本，使本地门禁继续运行。

## 退役原因

该做法会造成：

- 本机依赖未跟踪文件才能通过；
- clean checkout 和 CI 缺少同一资产；
- 真实契约缺失被临时文件掩盖；
- 后续 Agent 无法知道本地副本来源和生命周期；
- 删除、清理或换机后问题再次出现。

这与已验证的 TRAE Hook 事故同构：本地文件存在导致本机绿，远端 clean checkout 持续失败。

## 替代规则

1. 契约是代码门禁依赖时，必须进入受版本控制的权威位置。
2. 上游资产暂时无法修改时，门禁应明确阻塞并创建带 owner、截止时间和验收标准的工程任务。
3. 测试夹具只能放在已跟踪的测试目录，并明确与生产契约的差异。
4. 禁止使用 `.gitignore` 内文件满足发布门禁。
5. 兼容层必须具备 clean checkout 测试和明确删除条件。

## 验收

- clean checkout 不依赖本机私有文件。
- 缺失契约时门禁 fail-closed，并输出准确缺口。
- 修复资产进入 Git 后，CI 与本机结果一致。
