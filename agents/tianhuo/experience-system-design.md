# 天火智能体经验存储系统设计方案 v1.0

**版本**: v1.0
**日期**: 2026-04-22
**定位**: 经验数据→记忆系统→可复用资产的全链路存储方案
**适用范围**: 天火智能体 + awkn-programmer 技能包

---

## 一、设计背景

### 1.1 问题陈述

当前天火智能体产生的经验分散在：
- 天火.md（核心档案）
- 天火2.md（最佳实践）
- 天火3.md（运营历史）

这些经验缺乏系统性存储，难以实现：
- 高效检索和复用
- 版本追踪和更新
- 与 awkn-programmer 技能包的深度集成

### 1.2 设计目标

```
目标1：建立结构化经验存储仓库
目标2：实现 8 维分类索引体系
目标3：与 awkn-programmer 技能包无缝集成
目标4：支持版本追踪和增量更新
目标5：提供快速检索和场景匹配能力
```

## 三、分类体系

### 3.1 8维分类索引

根据 8 维结构化复盘方法论，经验存储系统采用以下分类：

| 维度 | 分类 | 经验项示例 |
|------|------|-----------|
| **目标达成度** | 成功经验/失败教训 | 决策准确率 >90% / <90% |
| **过程质量** | 执行流程/规范遵循 | P0加载/Safety Gate |
| **协作效率** | 智能体协作/通信模式 | 协作协议/消息模板 |
| **质量指标** | 代码质量/部署质量 | 验证清单/测试证据 |
| **文档一致性** | 文档规范/版本管理 | 决策日志/复盘模板 |
| **资产沉淀** | 最佳实践/踩坑教训 | 6类经验库 |
| **认知升级** | 能力成长/进化触发 | 成熟度矩阵/进化条件 |
| **功法改进** | 方法论升级/规则更新 | 决策框架/协作协议 |

### 3.2 资产评级 (3级)

| 评级 | 定义 | 示例 |
|------|------|------|
| **S级** | 可跨项目直接复用，效果显著 | 七层记忆系统、熔断机制 |
| **A级** | 场景受限但价值高，需适配 | 消息模板库、服务器操作 |
| **B级** | 参考价值，需要调整后使用 | 回滚模板、复盘模板 |

### 4.2 经验条目示例

```markdown
## 经验条目 EXP-001

- **ID**: EXP-001
- **分类**: 资产沉淀-记忆系统
- **评级**: S级
- **版本**: v1.0
- **来源**: 天火.md
- **创建时间**: 2026-04-22
- **标签**: [记忆系统, 七层架构, 上下文管理]

### 场景描述
天火智能体在跨会话任务中丢失上下文，导致重复工作和决策失误

### 核心做法
设计七层记忆架构：
- Intent（意图层）：用户根本意图
- L4（项目层）：跨会话项目记忆
- L3（任务层）：复杂任务上下文
- L2（会话层）：单次会话关键决策
- L1（操作层）：具体代码修改
- L0（碎片层）：快速备注
- Meta（元认知层）：模式识别

### 效果验证
记忆检索命中率显著提升，跨会话上下文保持完整

### 可复用规律
记忆系统应该分层设计，高频使用的内容应该靠近顶层

### 适用边界
- 适用：复杂任务、跨会话项目、多步骤操作
- 不适用：简单查询、快速问答

### 关联经验
- 相关：EXP-004（记忆检索最佳实践）
- 演进：EXP-001.1（Meta层利用率提升）
```

## 五、与 awkn-programmer 技能包集成

### 5.1 集成路径

```
经验数据 → 经验存储系统 → 知识提取 → awkn-programmer 技能更新
```

### 5.2 集成接口

| 场景 | 接口 | 输出 |
|------|------|------|
| 立项阶段 | 经验检索（决策框架） | 避免重复踩坑 |
| 开发阶段 | 经验检索（执行协议） | 流程规范 |
| 复盘阶段 | 经验写入 | 资产沉淀 |

### 5.3 集成触发条件

| 触发条件 | 动作 |
|----------|------|
| 完成 L3/L4 任务 | 写入经验条目 |
| 发现新的最佳实践 | 写入最佳实践库 |
| 踩坑后解决 | 写入踩坑教训库 |
| 能力有实质性提升 | 更新成熟度矩阵 |
| 规则有变更 | 更新协议文件 |

## 六、版本管理

### 6.1 版本号规则

```
主版本.次版本
- 主版本：重大架构变更
- 次版本：增量更新

示例：
v1.0 → v1.1（新增经验条目）
v1.1 → v2.0（架构重构）
```

### 6.2 版本追踪

每次更新记录：
- 更新日期
- 更新内容
- 更新者
- 变更原因
