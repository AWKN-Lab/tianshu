# 天火上下文分层压缩策略

> 版本：v1.0
> 来源：Alice 工程方法论 05-上下文与记忆.md
> 用途：长对话运行时上下文压缩

---

## 一、四层递进压缩策略

| 层级 | 触发条件 | 操作 | Token 成本 |
|------|---------|------|-----------|
| L0 | 短对话 &lt;10 轮 | 不压缩 | 0 |
| L1 | 中等对话 10-30 轮 | 轻量裁剪 | 0 |
| L2 | 长对话 30-50 轮 | 本地替换 | 0 |
| L3 | 超长对话 50+ 轮 | 摘要压缩 | 中等 |
| L4 | 极长对话 80+ 轮 | 全量压缩 | 重 |

---

## 二、L1 轻量裁剪（零成本）

### 裁剪内容

- 早期工具调用对（request+response），保留最近 5 轮
- 冗余的重复确认信息
- 用户多次说"继续"的纯推进语
- 已完成任务的中间状态信息

### 保留内容（必留）

- **任务分类 Packet**（永远保留）
- **用户明确要求记忆的内容**（带 tag）
- **safetyGate 拦截决策**（永远保留）
- **最近 5 轮完整对话**

---

## 三、L2 本地替换（零成本）

### 替换规则

- 相同工具的重复调用 → 替换为说明
  - 例：`[连续 3 次调用 search 工具，查询同一主题]`
- 相同步骤的重复执行 → 替换为说明
- 用户反复纠正同一问题 → 保留第一次和最后一次

---

## 四、L3 摘要压缩（中等成本）

### 摘要格式

```markdown
## 历史对话摘要
- [主题]：[一句话总结]
- [关键决策]：[决策点 1]、[决策点 2]
- [踩坑记录]：[坑 1]、[坑 2]
- [当前任务状态]：[明确阻塞/进行中/完成]

## 最近对话
[最近 10 轮完整保留]
```

### 保留规则

- 保留所有 Packet（压缩为 JSON snippet）
- 保留用户纠正、用户明确要求记住的内容
- 保留所有 safetyGate 决策

---

## 五、L4 全量压缩（重成本）

### 触发条件

- 对话轮次 ≥80 且 P0+上下文 ≥10K token
- 用户明确要求压缩

### 压缩产出

1. **结构化状态快照**：保存当前所有 Packet、记忆锚点、技能激活状态
2. **极简历史摘要**：≤1000 token
3. **状态恢复入口**：提供"继续对话"时的恢复步骤

---

## 六、压缩触发规则

### 自动触发

- 每轮对话后检查 token 总量
- 超阈值 → 询问用户是否压缩

### 手动触发词

- "压缩上下文"
- "精简对话"
- "太长了，简化一下"

### 压缩决策逻辑

1. 当前 token 预估
2. 下一轮对话预估增量
3. 若预计超 12K → 询问用户是否压缩
4. 默认选项：L2 轻量压缩

---

## 七、互斥守卫

- **压缩不能触发压缩**（见 agent.prompt §4.1）
- 同一轮对话不能执行多次压缩
- 压缩前必须先经用户确认
