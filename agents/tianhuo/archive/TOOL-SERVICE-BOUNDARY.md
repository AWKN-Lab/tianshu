# 天火工具/服务边界声明

> 版本：v1.0
> 来源：Alice 工程方法论"结构隔离"原则
> 判断标准：这个操作是用户视角有意义的动作吗？是 → 工具；否 → 服务

---

## 一、分类定义

| 类别 | 可见性 | 定义 | 示例 |
|------|--------|------|------|
| **工具** | AI 可见 | 用户视角有意义的动作，直接产生用户可感知的交付物 | 代码编写、文件搜索、API 调用 |
| **服务** | AI 不可见 | 系统内部支撑操作，用户不直接感知 | 上下文压缩、记忆提取、健康检查 |

---

## 二、工具清单（AI 可见）

| 工具 | 用户感知 | 只读 | 破坏性 | 来源 |
|------|---------|------|--------|------|
| 代码编写/修改 | 代码变更 | 否 | 是 | awkn-工程师 |
| 文件搜索/读取 | 搜索结果 | 是 | 否 | 内建 |
| API 调用 | 接口响应 | 否 | 视接口而定 | 内建 |
| 部署操作 | 部署结果 | 否 | 是 | awkn-部署 |
| 测试执行 | 测试报告 | 是 | 否 | awkn-工程师 |
| 代码审查 | 审查报告 | 是 | 否 | awkn-审核 |
| 技能加载 | 技能执行结果 | 否 | 否 | SKILL-REGISTRY |
| 文档生成 | 文档文件 | 否 | 否 | awkn-工程文档 |
| 复盘总结 | 复盘报告 | 否 | 否 | AWKN 复盘总结 |
| 浏览器自动化 | 页面截图/交互结果 | 否 | 否 | gstack |

---

## 三、服务清单（AI 不可见）

| 服务 | 用户不直接感知 | 触发时机 | 失败时降级 |
|------|--------------|---------|-----------|
| 上下文压缩 | 对话变长时自动触发 | 长对话（10+ 轮） | 不压缩，继续对话 |
| 记忆提取 | Evolve 阶段自动触发 | 任务完成时 | 跳过写回，记录 none + reason |
| 记忆去重 | 写入前自动触发 | evolutionWritebackPacket 生成时 | 不去重，直接写入 |
| 守门员判断 | Evolve 阶段自动触发 | evolutionWritebackPacket 生成前 | 全部走写回（保守模式） |
| 健康检查 | 启动时/定期 | 会话启动 / 核心文件变化后 | 跳过检查，继续运行 |
| 版本备份 | Skill 修改前自动触发 | Skill 自动微调确认后 | 不备份，直接修改（风险模式） |
| 入口一致性检查 | 核心文件变化后 | 修改 agent.prompt / MEMORY.md 后 | 跳过检查，手动验证 |
| 互斥守卫 | 被动触发机制触发时 | 压缩/复盘/写回触发时 | 警告不拦截（初期） |

---

## 四、边界模糊项

| 操作 | 工具还是服务？ | 判断理由 | 当前归类 |
|------|--------------|---------|---------|
| 记忆提取 | 服务 | 用户不直接感知"提取"动作，感知的是"天火记住了" | 服务 |
| Skill 路由 | 服务 | 用户不直接感知"路由"动作，感知的是技能执行结果 | 服务 |
| 上下文压缩 | 服务 | 用户不直接感知"压缩"动作，感知的是对话继续 | 服务 |
| 错误边界处理 | 服务 | 用户不直接感知"降级"动作，感知的是友好提示 | 服务 |
| 意图对齐 | 工具 | 用户直接感知"天火在问我确认" | 工具 |
| Card 出牌 | 工具 | 用户直接感知"天火给了选项/缩小了范围" | 工具 |

---

## 五、工具白名单（Skill 激活时）

当 Skill 激活时，限制可用工具集，防止越权操作：

| Skill | 可用工具 | 不可用工具 |
|-------|---------|-----------|
| awkn-工程师 | 代码编写、文件搜索、测试执行、API 调用 | 部署操作 |
| awkn-审核 | 文件搜索、代码审查 | 代码编写、部署操作 |
| awkn-部署 | 部署操作、文件搜索 | 代码编写、代码审查 |
| awkn-工程文档 | 文件搜索、文档生成 | 代码编写、部署操作 |
| awkn-执行检查 | 文件搜索、代码审查 | 代码编写、部署操作 |
| AWKN 复盘总结 | 文件搜索、复盘总结 | 代码编写、部署操作 |
