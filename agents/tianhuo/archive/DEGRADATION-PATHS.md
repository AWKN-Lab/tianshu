# 天火降级路径系统化

> 版本：v1.0
> 来源：Alice 工程方法论"可丢弃组件"原则
> 用途：每个外部依赖显式定义降级路径，系统不崩溃

---

## 一、降级原则

每个外部依赖必须满足：
1. **不崩溃**：依赖失效时系统继续运行（降级模式）
2. **可观测**：降级时输出原因，告知用户功能受限
3. **可恢复**：依赖恢复时自动切回正常模式

---

## 二、降级路径清单

### 2.1 向量检索

| 状态 | 检测方式 | 降级行为 |
|------|---------|---------|
| 正常 | 向量检索返回结果 | 正常流程 |
| 降级 | 检索超时/返回错误 | 降级为关键词搜索（Grep） |
| 失败 | 连续 3 次失败 | 禁用向量检索，切换为纯记忆文件扫描 |
| 恢复 | 检测到正常响应 | 自动切回向量检索模式 |

**降级输出**：
```
⚠️ 向量检索不可用，已切换为关键词搜索。
功能受限：无法进行语义相似度匹配。
```

---

### 2.2 MCP Server

| 状态 | 检测方式 | 降级行为 |
|------|---------|---------|
| 正常 | MCP 调用返回成功 | 正常流程 |
| 降级 | 单次调用超时 | 重试 1 次，失败则降级 |
| 失败 | 连续 2 次失败 | 禁用该 MCP Server，对应工具标记不可用 |
| 恢复 | 检测到 ping 成功 | 自动重连并恢复工具 |

**降级输出**：
```
⚠️ MCP Server [名称] 不可用，相关工具已暂时禁用。
```

---

### 2.3 记忆系统

| 状态 | 检测方式 | 降级行为 |
|------|---------|---------|
| 正常 | 记忆文件可读写 | 正常流程 |
| 降级 | 文件读取失败 | 尝试重建缺失文件 |
| 失败 | 重建失败或写入失败 | 切换为纯上下文模式，不尝试写回 |
| 恢复 | 文件恢复正常读写 | 自动切回正常模式 |

**降级输出**：
```
⚠️ 记忆系统不可用，当前会话切换为纯上下文模式。
本次会话的经验将在对话结束后尝试写回。
```

---

### 2.4 Skill 文件

| 状态 | 检测方式 | 降级行为 |
|------|---------|---------|
| 正常 | SKILL.md 读取成功 | 正常流程 |
| 降级 | 文件读取失败 | 使用 archive/ 本地索引 fallback |
| 失败 | 本地索引也缺失 | 使用天火原生自主执行逻辑 |
| 恢复 | SKILL.md 恢复可用 | 自动切回 Skill 路由 |

**降级输出**：
```
⚠️ [技能名] Skill 文件不可用，使用本地执行逻辑。
```

---

### 2.5 SKILL-REGISTRY 路由

| 状态 | 检测方式 | 降级行为 |
|------|---------|---------|
| 正常 | 路由命中 Skill | 加载对应 SKILL.md |
| 降级 | 路由命中但文件不可读 | 使用 fallback 自主执行逻辑 |
| 失败 | 无法读取任何 Skill | 使用天火原生自主执行逻辑 |

---

### 2.6 上下文压缩

| 状态 | 检测方式 | 降级行为 |
|------|---------|---------|
| 正常 | 压缩成功 | 正常流程 |
| 降级 | 压缩失败/超时 | 跳过压缩，继续原上下文 |
| 失败 | 压缩破坏上下文 | 使用上一轮快照恢复 |

---

## 三、降级状态持久化

降级状态写入：
- 路径：`archive/degradation-state.json`
- 内容：各依赖的当前降级状态
- 用途：天火重启时读取，避免重复尝试已失败的依赖

```json
{
  "vectorSearch": "degraded",
  "mcpServers": {},
  "memorySystem": "normal",
  "lastChecked": "2026-05-28T10:00:00Z"
}
```

---

## 四、自动恢复检测

每 10 轮对话检查一次降级状态：
- 向量检索：尝试一次轻量查询
- MCP Server：发送 ping
- 记忆系统：检查文件可读性
- Skill 文件：检查 SKILL.md 是否恢复

---

## 五、与互斥守卫集成

降级路径在以下场景可能触发互斥守卫：
- 压缩失败 → 尝试重新压缩 → 互斥守卫拦截
- 降级恢复 → 尝试切回正常模式 → 需用户确认
