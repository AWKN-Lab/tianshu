# 天火记忆去重与写入时序

> 版本：v1.0
> 来源：Alice 工程方法论 05-上下文与记忆.md
> 用途：记忆写入前检查重复；对话进行中禁止写入

---

## 一、写入时序约束

### 硬规则（Alice 优先）

- **对话进行中** → **禁止写入记忆库**（防止信息自我强化）
- **写入延迟** → 所有记忆写入延迟到 Evolve 阶段统一执行
- **守门员前置** → 写入前先经 agent.prompt §8.1 守门员判断

---

## 二、记忆去重规则

### 去重流程

```
候选记忆 → 精确匹配检查
    ↓（命中→跳过写入，记录去重标记）
语义匹配检查
    ↓（命中→跳过写入，记录去重标记）
通过 → 写入
```

### 精确匹配（L1）

检查以下字段是否完全一致：
- 记忆标题（或 intent 键）
- 核心事实（关键信息）
- 来源上下文

### 语义匹配（L2）

- 同主题不同表述
- 同一问题的不同解决方案
- 等价的步骤清单
- 重复的"踩坑记录"（仅保留最新 1 条）

### 去重标记

当检测到重复时，在现有记忆的 `meta.tags` 中追加：
- `duplicate-of: [原有记忆 ID]`
- `duplicate-detected: [日期]`
- **不创建新记忆，仅标记**

---

## 三、摘要模式切换

### 触发条件

- 同主题记忆条目 **≥10 条**
- 单个记忆文件 ≥5K token

### 摘要规则

1. 保留最早和最近的 2 条原始记忆
2. 其余条目压缩为：`[主题] 摘要（[条目数] 条已压缩）`
3. 摘要包含：核心事实、关键踩坑、验证结论
4. 原始条目保留在 `archive/memory-snapshots/` 中（可选）

---

## 四、写入校验清单

每次写入前检查：

- [ ] 对话已结束（Evolve 阶段）
- [ ] 守门员判断通过（writeback）
- [ ] 精确匹配检查通过（无重复）
- [ ] 语义匹配检查通过（无重复）
- [ ] 条目数未超限（或已切换摘要模式）
- [ ] 记忆层级正确（L0/L1/L2/L3）
